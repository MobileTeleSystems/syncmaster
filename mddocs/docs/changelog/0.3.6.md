# 0.3.6 (2026-08-18) { #0.3.6 }

### Improvements

- Drop FastAPI `dependency_overrides` feature. ([#409](https://github.com/MTSWebServices/syncmaster/issues/409))

    See [#14441](https://github.com/fastapi/fastapi/pull/14441).

- Cache Keycloak certs for JWT token validation. ([#410](https://github.com/MTSWebServices/syncmaster/issues/410))

    Previously every API request with KeycloakAuthProvider enabled made a request to Keycloak.

- Hide auth provider secrets and database password from logs. ([#413](https://github.com/MTSWebServices/syncmaster/issues/413))
- Update onETL from 0.16.x to 0.17.0.

    This makes writing to Postgres up to x2 faster.
